High Level Overview

  • Toggle Tabs: Show or hide the native Firefox tab bar with a single click.
  • Companion for Sidebars: Perfect for users of Tree Style Tab, Sidebery, or other vertical tab extensions.
  • Flexible Configuration: Use CSS to either hide the window controls along with tabs, or keep the native min/max/close buttons visible.
  • Sidebar Clarification: This add-on toggles the native Firefox tab bars (horizontal or the new built-in vertical tabs). It does not control third-party sidebar extensions like Tree Style Tab or Sidebery; those are still managed by showing or hiding the Firefox sidebar.
  • Dynamic Icon: The toolbar icon changes visually so you always know if the native tab bar is currently hidden or visible (if properly configured).
  • Quick Access: Right-click the extension icon in the toolbar to quickly access these options.

Instructions on how to setup and use this add-on

1. Enabling userChrome.css

(Skip this section if you already use userChrome.css)

  • First, go to about:config and set toolkit.legacyUserProfileCustomizations.stylesheets = TRUE to enable userChrome.css usage
  • Next, go to about:profiles and look for the profile that says This is the profile in use and it cannot be deleted
  • On the row for Root Directory, click on Open Folder to open the profile folder
  • Inside the profile folder, create a new folder called chrome if it doesn't exist
  • Inside the chrome folder, create a new file called userChrome.css if it doesn't exist

2. Entering CSS into userChrome.css

Handling horizontal tab bar (only)

FF133+: Current solution (RECOMMENDED)

#main-window[titlepreface*=" "] {
    #TabsToolbar {
        display: none;
    }

    #nav-bar {
        .titlebar-buttonbox-container {
            display: flex !important;
        }
    }
}

FF133+: Original solution (which requires separate min/max/close buttons if desired)

#main-window[titlepreface*=" "] #TabsToolbar {
    display: none;
}

Up to FF132: Legacy solution (Only if on FF132 or earlier)

#main-window #titlebar {
    overflow: hidden;
    transition: height 0.3s 0.3s !important;
}

/* Hidden state: Hide native tabs strip */
#main-window[titlepreface*=" "] #titlebar { height: 0 !important; }

/* Hidden state: Fix z-index of active pinned tabs */
#main-window[titlepreface*=" "] #tabbrowser-tabs { z-index: 0 !important; }

Handling horizontal and vertical tab bars (FF136+)

FF136+: Current solution (RECOMMENDED)

#main-window[titlepreface*=" "] {
    #TabsToolbar {
        display: none;
    }

    #nav-bar {
        .titlebar-buttonbox-container {
            display: flex !important;
        }
    }
	
    #sidebar-main {
        display: none;
    }
}

FF136+: Original solution (which requires separate min/max/close buttons if desired)

#main-window[titlepreface*=" "] {
    #TabsToolbar {
        display: none;
    }
	
    #sidebar-main {
        display: none;
    }
}

How it works: This add-on toggles between adding and removing a " " space character to the titlepreface property. Your CSS acts upon this change to show/hide the bars.

Save your userChrome.css file and restart Firefox for changes to take effect.

Additional Information

Add-on Icon Meanings

Tabs are Visible: Represents support for both standard and vertical tab bars.

Tabs are Hidden: Only the outer frame is shown, indicating tabs are suppressed.

Action Required: To enable the dynamic theme matching shown in the graphics above, follow the Icon Coloring Instructions.

Minimize/Maximize/Close Buttons

If you use a solution that hides the native titlebar buttons, you can still control the window using:

  • The (RECOMMENDED) CSS solution above to move buttons to the navigation bar.
  • Keyboard shortcuts: Alt+Space then N (Minimize) or X (Maximize).
  • Right-click the taskbar icon.
  • Windows key + Arrow keys.
  • Emulation add-ons: Minimize, Maximize, Close.
